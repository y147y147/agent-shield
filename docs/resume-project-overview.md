## 0. 一句话定位

**为 LLM 智能体设计并验证的"可量化攻防 + 自动化安全测试"框架**：
不仅能"攻"（14 个攻击模块模拟各类 Agent 行为层攻击），还能"防"（6 层运行时防线），
且每一处防护都用**双向决策门（安全分 + 能力分）**验证为真实有效、不误伤业务。

## 2. STAR 主述（简历正文）

**S · 背景**：LLM 智能体通过工具调用获得真实行动能力，也打开了传统安全不覆盖的
"行为层攻击面"（对应 OWASP Top 10 for Agentic Applications）——诱导下智能体会真的
`read_file` / `run_command` 执行越权动作，普通模型只能"拒绝/说错"，智能体却能"动手"。

**T · 任务**：独立从 0 到 1 实现"红队攻击 + 蓝队防护 + 攻防闭环验证"一体化框架；
要求每个防护改动必须通过**可量化决策门**，避免只满足演示、不解决实际问题。

**A · 行动**：
- 插件化攻击框架：14 模块、覆盖 10 类 OWASP 风险，模块最小 ~30 行接入；攻击载荷在真实
  框架（LangChain AgentExecutor）可打穿。
- 可插拔 6 层防护 + 统一运行时钩子（含输出端第四钩子），打通本地与真实 LangChain 全部退出路径。
- 双向决策门：安全分（ASR 攻击成功率 / FPR 误报率）+ 能力分（良性任务完成率），防误伤。
- 全工程闭环 M1–M5（数据层 / 自改进 / 修复 / Web 控制台 / 成本门禁），全部真实跑通。

**R · 结果**：
- 每个攻击向量完成"裸机可打穿 → 加固归零"闭环，代表向量 ASR 由 **100% 降至 0%**，
  同时良性任务完成率保持 **100%（无误伤）**。
- 用 **AgentDojo 官方仓库逐字攻击模板**做第三方横向对比：离线靶场 **86%→29%**、
  真实模型（DeepSeek）**29%→14%**，并如实上报穿防残余（不刷分）。
- 发现真实模型误报盲区（FPR 61~81%），及「更强推理=更抗诱导」的反直觉结论。

## 3. 关键量化指标（弹药）

- **14** 个攻击模块 · **6** 层防线 · **10/10** OWASP ASI 类别 · **540+** 自动化测试
- ASR：代表向量 **100% → 0%**（加固归零闭环）；能力分 **100%** 不降（零误伤）

- 单人从 0 到 1 · M1–M5 全工程闭环 · 单文件零前端外部依赖 · CI/自检一键绿

## 4. 研究亮点（体现深度，面试谈资）

1. **真实误报盲区**：DeepSeek 模型 mock 上 FPR 0%，真实测试分别达 61%/81%——
   只跑 mock 会系统性漏掉真实误报。
2. **"更强=更抗诱导"不成立**：deepseek-reasoner 裸脆弱性反而高于 chat（19% vs 14%）。
3. **防线盲区实证 + 闭环修复**：首个"加固后不归零"的向量（workspace_exfiltration），
   补齐第四输出端钩子 + 敏感文件最小权限后归零，验证"任何防护都要能证明有效"的哲学。
4. **默认抗性与语境相关**：真实模型对显式越权（tool_impersonation）天然拒止，但对
   权威/审计语境（human_trust, workspace_exfiltration）反而更易配合——红队要"打语境"而非"打显式"。
5. **外部基准不刷分**：用 AgentDojo 真实攻击文本自测，如实上报 2 条穿防残余
   （含只读命令有意放行、TODO 前缀直述式缺口）。

## 5. 工程化与企业级细节（加分项）

- **决策门 AI-SI 化**：`gate` 把「对抗回归 + 红队门 + FPR 不劣化」钉进 CI，红线不回归。
- **上架工程完备**：一键自检脚本（镜像 CI + 硬编码密钥扫描）、CHANGELOG/AUTHORS/CONTRIBUTING、
  PyPI 可信发布 CI（零明文 token）、安全声明、SARIF 报告可接 Code Scanning。
- **成本可治理**：M5 成本门禁——任务/每日预算超限自动熔断（`aborted` 落库 + 非零退出）。
- **可观测**：Web 攻防控制台、6 表持久化（campaign/traces/verdicts/costs/findings 状态机）、
  审计代理、错误/命中定位（locate_defense_hits）。
